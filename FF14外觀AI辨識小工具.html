辨識設定

預設使用 PaddleOCR 在本機瀏覽器處理圖片；如改用 AI 時，圖片會傳送至所選服務商。API Key 僅儲存在本機瀏覽器。

使用 PaddleOCR.js＋PP-OCRv5 輕量模型，在瀏覽器內辨識圖片文字，不需 API Key；首次使用需下載模型。適合有裝備名稱文字的截圖。
💡 Google Gemini API Key 取得步驟：
  1. 前往 Google AI Studio 官網 (點此開新視窗)。
  2. 登入 Google 帳號，點擊 「Get API key」 後再點擊 「Create API key」。
  3. 預設自動啟用 gemini-3.5-flash-lite 與 gemini-3.1-flash-lite 雙重輪詢。
