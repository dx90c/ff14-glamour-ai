# V2.6.1 探索功能整合測試

分支：`codex/integrate-v2.6.1-explore`。基底：主支 `bd7c00c`（Update v2.6.1）。已通過本機驗收，依使用者授權推送整合分支；未合併主支，未部署正式網站。

## 保留與移植

| 項目 | 處理 |
|---|---|
| 主支同篇多圖讀取、左右穿搭分組、染色歸屬 | 保留主支流程，不以探索版覆蓋 |
| 縮圖、多套切換、同篇其他照片預覽 | 移植；表格、圖片、標題及來源使用同一份成果清單 |
| 多篇批次 XLSX | 每套含圖一頁，另有目錄；匯出全部按鈕位於切換區上方 |
| 3／4 倍分區重掃 | 移植；限制在目前穿搭分區，失敗或裝備減少時保留原結果，不覆蓋已讀到的染色 |
| 截斷名稱與部位推測 | 移植日文六列規則，保留疑似標記、歧義與不規則排版拒絕條件；分組各自推測 |
| 貼網址即辨識 | 移植；尊重選取範圍，多篇分行，依貼文 ID 去重 |
| 結果快取 | 獨立 IndexedDB，保留分組範圍；辨識規則／資料版本改變即失效，24 小時有效，最多 20 篇／100 MB |
| 加權相似字 | 兩邊核心相同，保留主支實作與門檻 |
| 收藏、衣櫥、推薦、相似圖片搜尋、排版設定 | 不載入、不移植，也不刪除原有瀏覽器資料 |

## 驗證

- 主支回歸：名稱、韓文、染色、歧義拒絕、灰機與 Google、來源欄位、CSV 命名、含圖 XLSX。
- 原始雙套 OCR 記錄：左右各五件，十件精準 ID 保留；快取後仍保留左右分區，右側重掃不改左側，失敗還原。
- 連續貼兩篇：兩套往返切換、快取略過重抓、批次含圖 XLSX 三頁（含目錄）。
- 漸進顯示：第一套完成即顯示，後續圖片／貼文逐步追加，不切回整頁載入，也不打斷目前選取；延遲第二、第三篇的測試通過。
- 真實截斷日文貼文 `2112428433376706580`：六件匹配，其中三件疑似；放大重掃後六件保留。
- 同名文字分布左右兩側時不互相去重；分區重掃只保留該側文字。

探索版來源包含尚未提交的工作目錄修改，讀取時雜湊記於 `source-hashes.json`；原探索目錄未修改。

測試頁：`http://127.0.0.1:5182/`。尚未製作正式發布 ZIP，也未變更正式下載連結。

限制：截斷名稱推測目前只接受有足夠定位證據的日文六列排版；重掃無法恢復圖片以外的文字。尚未完成所有使用者圖片的人工驗收。
