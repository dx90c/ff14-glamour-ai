## Update v2.4.3

- OCR 模型改由本站 GitHub Pages 提供，保留官方來源、授權與 SHA-256 清單。

- 新增含原圖的 XLSX 匯出，採 A–E 裝備表格、F 欄圖片的版面；圖片等比例貼齊寬度或高度，不裁切、不拉伸。
- XLSX 保留取得方式、染色、外語原名、灰機及 Google 超連結、疑似匹配與穿搭提醒。
- 檔名自動帶日期與時間，優先使用標題；無可用標題時使用身體裝備名稱。
- 移除「一鍵複製到 Excel」，保留 XLSX、CSV、TXT 三顆匯出按鈕。
- 加入小字與部分未匹配區域的自動放大重讀，最多八個區域各讀一次；失敗保留原結果，名稱匹配門檻不變。
- 改善附近雙語裝備名稱合併、染劑歸屬與雙色槽配對；兩個明確色槽使用相同染劑時保留兩槽。
- 更正下載版說明：免費 OCR 需要 HTTP(S)，直接雙擊 HTML 僅可使用 AI 模式；含圖 XLSX 匯出需保留 xlsx 元件資料夾。
- 更新線上版、固定檔名下載版、中文 README 與 ExcelJS 授權文件。

# update 2.3.0

累積 2.2.x 至 2.3.0 的改進：

- 固定下載版檔名為 FF14外觀AI辨識小工具.html，網頁版入口維持 index.html；舊版保留於 old。
- 裝備庫改為獨立 JSON，HTML 不內嵌完整裝備資料；網頁版首次自動載入，下載版首次手動匯入。
- 以物品 ID 整合 InfSein 名稱、Teamcraft 繁中名稱與取得方式、LuminaSupplemental 補充來源。
- 支援繁中、簡中、英、日、法、德名稱；任務、商店、交換、副本、物品箱及商城等來源由既有庫提供。
- 三庫管理合併版本、資料日期、遊戲版本依據、公開來源及更新狀態，移除冗餘取檔日期，支援 Esc 關閉。
- 三庫一鍵同步，逐庫保存；已最新的庫略過下載，失敗後只重試未完成或有更新的庫。
- 下載版選擇資料夾後自動保存 JSON；網頁版同步保存瀏覽器，提供 HTML 與 JSON 下載連結。
- 名稱精準匹配優先；加入 OpenCC 字形輔助、相似字加權與長名稱兩字容錯，歧義不自動選取。
- 模糊結果在表格、灰機按鈕及剪貼簿／CSV／TXT 匯出標示疑似匹配。
- 保留灰機直達 → 站內搜尋 → 鴨鴨手氣，Google 備援維持原樣；預查失敗保留站內搜尋。
- 加入同步／上傳防重複與 JSON 驗證，保存失敗不冒充成功。

驗證：腳本語法、六語精準匹配、真實來源、簡繁／錯字／兩字容錯、歧義、匯出標示、版本解析、部分失敗重試及 JSON 關聯。未呼叫付費辨識 API。
